# Smuggy support

Smuggy is an Xray VPN and proxy client for your Mac's menu bar, made by [Skrrt LLC](https://skrrt.sh).

- **Website:** [smuggy.skrrt.sh](https://smuggy.skrrt.sh)
- **Privacy policy:** [smuggy.skrrt.sh/privacy](https://smuggy.skrrt.sh/privacy/)
- **Support:** [smuggy.skrrt.sh/support](https://smuggy.skrrt.sh/support/) or [support@skrrt.sh](mailto:support@skrrt.sh)
- **Report a problem:** [open an issue](https://github.com/skrrt-sh/smuggy-support/issues/new). Smuggy's own
  Report a problem fills one in for you. Leave out server links and keys: issues are public, and we never need them.

This repository holds the website and Smuggy's public issue tracker. Smuggy's source is not here. Every push to `main`
builds the site with Jekyll and publishes it to the Cloudflare Pages project `smuggy` (Skrrt LLC account) through
GitHub Actions.
